# Laboratorio de Ciberseguridad

**Estudiante:** Sebastián Mesa Meneses  
**Proyecto:** Laboratorio de Ciberseguridad  
**Modalidad:** Individual

## Descripción

Este repositorio contiene el desarrollo de un laboratorio práctico de ciberseguridad compuesto por ocho módulos. El propósito es reconocer, comprender y demostrar diferentes técnicas y escenarios relacionados con la seguridad informática mediante contenedores Docker y servicios desplegados en Render.

## Estructura del proyecto

| Módulo | Descripción |
|---|---|
| 00-servidor-dmz | Servidor web que simula una zona desmilitarizada (DMZ). |
| 01-ataque-dos | Simulación controlada de solicitudes HTTP concurrentes. |
| 02-escaneo-puertos | Exploración de puertos del servidor de laboratorio. |
| 03-fuerza-bruta-rutas | Enumeración de rutas y recursos web. |
| 04-exfiltracion-dns | Demostración educativa de transferencia de datos mediante consultas DNS. |
| 05-cadena-suministro | Simulación de un componente de software comprometido. |
| 06-credential-stuffing | Demostración con credenciales ficticias. |
| 07-proxy-mitm | Proxy que permite observar y modificar respuestas HTTP. |

## Tecnologías

- Python
- Docker
- Shell Script
- Git y GitHub
- Render

## Consideraciones de seguridad

Las actividades de este laboratorio tienen fines exclusivamente educativos. Las pruebas se limitarán a los servicios creados para este proyecto, utilizando datos y credenciales ficticias. No se realizarán pruebas contra sistemas de terceros sin autorización.
